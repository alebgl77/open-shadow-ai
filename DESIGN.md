# Visual system

The Open Shadow AI console uses a restrained operational aesthetic for ordinary office environments: graphite and navy surfaces, a teal signal accent, legible metadata, compact evidence tables, and generous separation between primary decisions.

The aperture mark is an open ring plus a signal dot. The open edge represents incomplete visibility; the dot represents observed evidence. The source of truth is `docs/assets/brand-mark.svg`, mirrored at `frontend/public/brand-mark.svg`.

## Tokens

| Role | Value |
| --- | --- |
| Canvas | `#0c1217` |
| Panel | `#10191f` |
| Raised surface | `#162129` |
| Border | `#3c4d57` at contextual opacity |
| Signal accent | `#65dbc6` |
| Body typography | IBM Plex Sans when locally installed, then Segoe UI |
| Technical identifiers | IBM Plex Mono when locally installed, then Consolas |

No remote fonts or decorative image assets are needed. Source status uses text plus color; keyboard focus has a visible teal outline. Motion respects reduced-motion preferences. The mobile sidebar is an explicit drawer, with a close overlay and a labeled menu control. Wide evidence tables scroll within their containers. Primary links and actions retain their keyboard semantics.

Do not equate absence of evidence with safety, installation with usage, activity with data disclosure, a reported model with verified provenance, or governance intent with runtime enforcement.
